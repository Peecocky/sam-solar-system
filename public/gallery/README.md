# Art Gallery image slots

Drop replacement images in this folder using these exact names:

- `hero.jpg`
- `art-01.jpg`
- `art-02.jpg`
- `art-03.jpg`
- `art-04.jpg`
- `art-05.jpg`
- `art-06.jpg`

The `/art` page keeps its designed placeholder visible when a file is missing and automatically covers it when the matching image exists.
